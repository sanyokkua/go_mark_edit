## 7. Proposed mapping

**Unit (Go, `go test ./internal/...`, keep same-package but move to `_test` package where feasible)** — keep: all `internal/apperr/{classified_error,wire,results}`, `internal/file/*` (except MOCK-SELF), `internal/db/*`, `internal/settings/*`, `internal/gate`, `internal/logging`, `internal/bootstrap`, `internal/appmodel/*` behaviour files. **Unit (frontend, Jest → `frontend/tests/unit/`)** — keep as-is (after stripping ID prefixes/`Proves:`): all `src/logic/**` tests except `useDocumentCommands.test.ts:200-260` (move the TS-AST scan to Lint); primitives; `AppearanceControls`, `ClosePrompt`, `ExternalChangePrompt`, `TabContextMenu`, `EditorContextMenu`, `PreviewPane`, `SettingsDialog`, `Launcher`, `DocumentIdentity`, `NormalizationPrompt`, `StatusBar` (drop its 9 CSS asserts), `MarkdownView`, `CodeEditor.test.tsx` (drop 4 text asserts), `i18n/catalog`, `markdown/renderer` (drop 5 text asserts), `format/formatting`, `scripts/generate-editor-themes.test.mjs`. **Integration (frontend, Jest with real store + mocked bridge only → `frontend/tests/integration/`)** — merge `EditorView.test.tsx` + `editorSession.integration.test.tsx` into `EditorView.integration.test.tsx`; merge `SettingsMenu.test.tsx` into `ShellMenuRow.test.tsx` minus its 35 text asserts; slim `DocumentTabs.test.tsx` to behaviour (delete the 8 CSS tests, ~lines 127-260); rewrite `App.test.tsx` to un-mock `AppShell`/`EditorView` and keep only startup/hydration/notification journeys (target ≤ 15 tests) — everything else it covers is already in `appModelProjection`/`actionDispatcher`.
