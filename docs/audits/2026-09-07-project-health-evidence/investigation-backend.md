Two independent SQLite-busy string classifiers: `isRecentSQLiteBusy` (`recent…:211`) vs `isTransientSQLiteBusy` (`db/db.go:252`). `sameRecentFiles` (`recent…:199`) ≡ `sameStringSlice` (`close_plan.go:664`) in the same package. ## 8. Concurrency model (source-level)

`service.mu` guards all model state; every command is _lock → snapshot → mutate → emit under lock → unlock_. The **emitter is invoked while holding the write lock** (`publishLocked`, `service.go:924-940`; `RuntimeStatePatchEmitter` → `runtime.EventsEmit`). _(inference)_ Wails v2 dispatches Go-side `EventsOn` listeners synchronously, so any future Go listener calling back into the model deadlocks; no such listener exists today, and the invariant is undocumented. Disk IO is correctly outside `mu`: `persistLayout` (`service.go:643-647`), `coordinator.Commit` (`save.go:318`), `recentFiles.Promote` (`file_lifecycle.go:280-284`). Per-document `DocumentWriteCoordinator.mu` serialises replacements; `waitForIdle` (`write_coordinator.go:110`) is the drain. Lock order `service.mu → conflictQueue.mu` is consistent (`conflict.go:459,466`). `SettingsService` releases its lock before calling observers (`settings/service.go:44-52`) ✓. No `go` statements in `internal/`; all asynchrony is `time.AfterFunc`.

## 9. `cmd/native-evidence` verdict

Separate `package main` under `//go:build native_evidence` (3 prod + 3 test files, ≈1,600 lines). It **does reuse** `application.NewApplicationContextHolder` for the service graph (`main_native_evidence.go:48`) — not a second DI root — but it is a **second host root**: a verbatim copy of `main.go`'s Wails options, close coordinator, native-window adapter and menu wrapper (see §3f), an ad-hoc string `switch` over scenario names (`:102-120`, `:249`), a fault-injecting `FileUtilsServiceAPI` (`:228-257`), and a private file logger (`:308-333`). It depends on production seams that exist only for it (`SetWriteCommitObserver`, `SetLayoutTimer`/`LayoutTimer`, post-construction dialog setters). The explicit-save driver calls `AppModelService` methods directly (`explicit_save_latency_scenario.go:47-53`), bypassing the bound handlers it claims to measure; the report metadata admits this (`autosave_latency_scenario.go:314-315`).
