## Reproduce the Go probes without editing tracked tests

Use a checkout at the audited commit with its dependencies installed. These are audit probes, not ready-made regression tests: for example, the retention probe must guard nil before logging retained fields once the defect is fixed. The memory/race tests intentionally reach service-level states, and scheduling hooks extend existing preemption windows. They do not establish how frequently a native user encounters the race.

From the repository root, create an overlay JSON in a new temporary directory. This reads the preserved sources and substitutes them only for compilation:

```sh
rtk proxy python3 - <<'PY'
from pathlib import Path
import json
import tempfile

root = Path.cwd().resolve()
evidence = root / 'docs/audits/2026-09-07-project-health-evidence'
temp = Path(tempfile.mkdtemp(prefix='gomark-audit-repro-'))
replacements = {}
for original, captured in [
    ('internal/appmodel/save_test.go', 'appmodel-probe.go.txt'),
    ('internal/settings/repository_sqlite_test.go', 'settings-probe.go.txt'),
]:
    copy = temp / captured.removesuffix('.txt')
    copy.write_bytes((evidence / captured).read_bytes())
    replacements[str(root / original)] = str(copy)
overlay = temp / 'overlay.json'
overlay.write_text(json.dumps({'Replace': replacements}))
print(overlay)
PY
```

Use the printed absolute path as `OVERLAY_PATH` below. Run separately so each package's exit is unambiguous:

```sh
rtk proxy go test -race -overlay=OVERLAY_PATH ./internal/appmodel -run TestAudit -count=1 -v -timeout=30s
rtk proxy go test -overlay=OVERLAY_PATH ./internal/settings -run TestAuditAppearanceGroupAtomicityUnderSQLiteFailure -count=1 -v -timeout=30s
```

Expect a nonzero Go exit on the audited code. Do not append a successful `tail` command and then cite its exit as the test result. The preserved overlays retain existing test bodies but only the `TestAudit` probes are selected in these diagnostic commands; ordinary full-suite results were collected separately.
